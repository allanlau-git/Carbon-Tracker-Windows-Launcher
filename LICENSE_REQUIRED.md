# License decision required before release

The requested goal is to release this launcher under the same open-source license as the Sustainability Monitoring Hub.

At preparation time (8 August 2026), the upstream repository:

https://github.com/msf4-0/Sustainability-Monitoring-Hub-202602

does not contain a `LICENSE` file or an explicit license statement in its README. Therefore there is currently no upstream open-source license to copy.

## Before public release

1. Select an OSI-approved open-source license for the Sustainability Monitoring Hub.
2. Add it as `LICENSE` at the root of the upstream repository.
3. Add the identical license text as `LICENSE` at the root of this launcher repository.
4. Add the SPDX identifier to source-file headers if your chosen license/project policy requires it.
5. Confirm that all third-party material you redistribute is compatible with the selected license.

## Common choices

- **MIT** — short, permissive, simple redistribution requirements.
- **Apache-2.0** — permissive and includes an express patent grant.
- **GPL-3.0** — copyleft; redistributed derivative works must remain under GPL-compatible terms.

This document intentionally does not select a license on behalf of the copyright holder.
